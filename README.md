# JustHome (Next.js)

Emlak teması — **Next.js 16**, **React 19**, **next-intl** (az / en / ru).

## Hızlı başlangıç

```bash
npm install
npm run dev
```

Uygulama varsayılan olarak [http://localhost:3000](http://localhost:3000) adresinde açılır.

## Dokümantasyon

Proje yapısı, rotalar, i18n ve layout kuralları için depo kökündeki **[PROJE-DOKUMANTASYON.md](../PROJE-DOKUMANTASYON.md)** dosyasına bakın.

## Komutlar

| Komut | Açıklama |
|--------|-----------|
| `npm run dev` | Geliştirme (Turbopack) |
| `npm run build` | Üretim derlemesi |
| `npm run start` | Üretim sunucusu |
| `npm run lint` | ESLint |
| `npm run sass` | SCSS → CSS izleme |
